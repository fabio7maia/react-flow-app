Both adapters read `enabled` on every event, so the consent can change while the app runs: nothing is sent before the opt-in, and the
stream starts at the next event after it. Only the actions you list are sent, with what you pick from the payload.

Pass `analytics` in the Provider's `adapters`. See [analytics](/guides/analytics/) for the page views and flow events each adapter sends.
