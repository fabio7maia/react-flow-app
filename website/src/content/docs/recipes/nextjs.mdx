The React entry is marked `'use client'`, so `FlowProvider` must be rendered from a client component. Import `AppFlows` from a server
component (a page or a layout) as usual.

On the server there is no `window`: the `browserHistory` adapter skips the deep link and the Provider starts at `initial`, so the first
render is the initial step and HTML and hydration agree. Lazy screens show the `fallback` until they load on the client.
