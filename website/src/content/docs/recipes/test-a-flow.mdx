The engine has no DOM, so a flow test is plain Node: dispatch actions and read the snapshot. `getPaths` generates one test per reachable
step. `engine.coverage()` lists the transitions no test walked, to write by hand.

Generated tests cover the navigation map, not the UI: see [what they cover today](/guides/testing/#what-generated-tests-cover-today).
